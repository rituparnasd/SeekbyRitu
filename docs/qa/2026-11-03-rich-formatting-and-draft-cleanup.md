# Rich formatting and requested draft cleanup

The basic list toolbar is replaced by a locally served Quill editor in Billing and Products & Services. Supported controls: bold, italic, underline, strikethrough, superscript/subscript, five font families, point sizes 8–48, text colour/highlight palettes, headings, left/centre/right/justified alignment, single/1.15/1.5/double line spacing, lists, indentation, undo/redo and clear formatting. Existing text is loaded without rewriting business rules. A hidden original field preserves normal form submission.

Formatting is stored as validated text-only Delta operations beside the plain text, inside existing encrypted catalogue/invoice snapshots. Arbitrary HTML, embeds, remote images, unknown styles, invalid colours and mismatched text are rejected. Editor assets are served from installed local dependencies; no remote CDN or relaxed script policy is used. Inline font features, colours, highlights, alignment, list markers and spacing render in PDFs, including catalogue-selected invoice descriptions and approved programme agreements. Issued snapshots retain their original data.

The generic placeholder error now quotes the actual unfinished wording, with surrounding context, and explains how to replace it or save unapproved. Errors remain visible below the form without clearing edits. Save As Draft lets the coach preserve unfinished product terms. Completed language such as “All outstanding terms have been agreed” and normal obligations to provide or explain a privacy notice do not trigger the old broad check. Approval is still not silently granted to unresolved terms.

The owner explicitly requested deleting all existing Billing drafts. A one-time production migration removes only unissued Draft records last updated no later than 2026-11-03T17:38:11Z. It preserves receipts, payments, issued/referenced documents, products, clients and test users. A metadata marker prevents rerunning against future drafts, and Admin → Run Live Check reports the count after deployment. The transaction and advisory lock protect concurrent writes. This workspace cannot directly inspect or change Render's live database; the cleanup takes effect on deployment, not at GitHub push time.

Verification: all 45 tests in the complete regression suite passed; additional browser checks verified all four alignments and exercised the actual font/size/colour/highlight/superscript/line-spacing toolbar and approval warning. A generated PDF was inspected for embedded fonts, sizes, colour and visible styling. Text-only validation and PDF long-word wrapping/page-boundary tests cover unsafe payloads and oversized content. Cleanup tests verify the one-time marker, cutoff and preservation of financial records and newer drafts. No actual email or payment was sent.
