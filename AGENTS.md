# Project language

Use American English for all new application text, labels, notifications, emails, document templates, invoices, receipts, and service agreements. Examples: personalized, program, enrollment, color, behavior, counseling, authorized, canceled, customize.

Preserve client-entered answers, journals, names, historical sent emails, signed agreements, and issued financial records. Do not rename existing database keys, API fields, status tokens, or file paths merely to change spelling. Language changes must not change business terms, amounts, permissions, or workflows.
